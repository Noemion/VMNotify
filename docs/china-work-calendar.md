# 中国工作日定时连接

“每天”不使用节假日日历。“中国工作日”包含普通周一至周五及调休上班日，排除国务院公布的整个放假区间和普通周末。

按 Windows 本地时间执行，跨午夜时段归属于开始日期；例如工作日 22:00 至次日 07:00，即使次日是假期也在 07:00 断开。时间结束不包含在连接时段内。

内置日历支持 2025、2026 年，离线可用。日历来自以下国务院办公厅通知的政府网站转载：

- [2025 年放假调休安排](https://www.forestry.gov.cn/c/www/szxx/594663.jhtml)
- [2026 年放假调休安排](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html)

后续年份以官方公布为准，通过软件更新补充 `ChinaWorkCalendar.cs` 中的数据并增加测试。未覆盖的年份不会简单按周一至周五猜测：工作日模式停止连接，并显示更新日历的提示；每天模式不受影响。地方性假期和单位自定休息日不在此全国性日历范围内。
