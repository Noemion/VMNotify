# 中国工作日定时连接

“每天”不使用节假日日历。“中国工作日”包含普通周一至周五及调休上班日，排除国务院公布的整个放假区间和普通周末。

按 Windows 本地时间执行，跨午夜时段归属于开始日期；例如工作日 22:00 至次日 07:00，即使次日是假期也在 07:00 断开。时间结束不包含在连接时段内。

内置日历支持 2025、2026 年，离线可用。日历来自以下国务院办公厅通知的政府网站转载：

- [2025 年放假调休安排](https://www.forestry.gov.cn/c/www/szxx/594663.jhtml)
- [2026 年放假调休安排](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html)

在“设置 → 节假日日历”点击“立即更新”，无需升级软件即可获取当年和次年的安排。在线数据来自第三方开源项目 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn)，该项目根据国务院公告整理 JSON；下载地址为 `https://raw.githubusercontent.com/NateScarlet/holiday-cn/master/{年份}.json`，不需要密钥。下载前后会校验年份、公告来源、日期范围、重复日期与年度数据的基本完整性。下一年公告涉及的上一年 12 月日期也会应用。

自动更新默认关闭，可设置每月 1–31 日及开始时间（HH:mm），点击“保存设置”后生效；例如每月 15 日 09:00。不足所选日期的月份按月末执行，例如 31 日在 2 月落到 28/29 日。按 Windows 本机时间执行，程序需要运行（可隐藏到托盘）。程序在更新日开始时间之后启动或从休眠恢复，会在 30 秒内检查；不会补跑已错过的日期，也不会唤醒电脑。

当日失败后距上次尝试一小时重试，成功后停止，跨天后等待下个月。手动更新不受定时限制，更新日当天手动成功也会停止当天自动重试。重启保留最近尝试和成功时间，避免一小时内重复自动请求。界面显示覆盖年份、最近尝试、最近成功、结果及下次自动尝试；尚未公布的次年（404 或空占位文件）单独标注，当年检查完成仍计为成功。网络错误、格式错误或写盘失败不算成功。

日历和更新记录保存为设置文件旁的 `china-work-calendar.json`（安装版位于 `%LOCALAPPDATA%\VMNotify`，便携版位于程序目录）。先校验并原子保存，再让新日历立即参与定时连接判断。失败时保留已有数据，离线和重启后仍可使用；缓存损坏会显示提示并回退内置数据。

未覆盖的年份不会简单按周一至周五猜测：工作日模式停止连接，并显示更新日历的提示；每天模式不受影响。地方性假期和单位自定休息日不在此全国性日历范围内。
